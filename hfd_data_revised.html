Introduction

The data set includes information on EMS events, fire events, and response totals for each station. This allows us to compare activity levels and understand which stations handle the highest workloads. Understanding how emergency calls are distributed across stations can help identify which areas of Houston have higher demand. The purpose of this project is to visualize the data in a way that makes it easier to interpret patterns, compare stations, and understand how EMS and fire activity relate to each other.

Real world relevance: This type of analysis is important because emergency call volume affects response times, crew workload, and community safety. Identifying which stations are the busiest can improve emergency service operations.

Problem

In this report I try to answer: which Houston Fire Department stations are the busiest, and how do EMS and fire events relate to each other? The reason this is important is because for so many years Houston fire department has always had staffing issues not having enough fire fighters for the city. The main reason is due to a salary raise that HFD was trying to fight for many years. Not until recently did they approve of which was last year and now that the salary has also increased more and more people are willingly to apply to become a firefighter. So my data is show how busy the stations are throughout Houston to help with placing more firefighters depending on which station is needed, also for better equipment based on the volume of calls each station gets.

To address this problem, I analyzed station level data on EMS and fire events and created visualizations that compare call volumes across all stations. By filtering the data, ranking stations, and using bar charts and scatter plots, I was able to identify which stations are the busiest and slowest.

Emt events
hfd %>%
  filter(!is.na(EMS.Events), EMS.Events > 0) %>%  # remove stations with no incidents
  mutate(Station = factor(Station)) %>%  #  make stations discrete that do not have activity
  ggplot(aes(x = Station, y = EMS.Events)) +
  geom_col(fill = "blue") +
  geom_text(aes(label = Station),
            vjust = -0.3,
            size = 3,
            color = "black") +
  labs(
    title = "EMS Events by Station",
    x = "Station Number",
    y = "EMS Events"
  ) +
  theme_minimal() +
  theme(
    axis.text.x = element_blank(),  # remove number on the x axis
    axis.ticks.x = element_blank(),  # remove tick marks
    plot.title = element_text(size = 16, face = "bold")
  )

Key Findings

  • EMS and Fire activity are not evenly distributed across stations. Some stations handle much higher call volumes.
  • Stations with higher EMS events often also have higher fire events, suggesting certain areas have generally higher emergency demand.
  • The relationship between EMS responses and fire responses indicates that resource needs may be similar across certain high demand stations.

Limitations

  • The data set reflects only time period and may not represent long term trends.
  • The data is aggregated by station and event type, so it does not include detail call level information.
  • The data did not show a longitude or latitude which would’ve showed a more precise location of where each incident happens across Houston.
  • The data also does not specify what type of calls were made specifically but based on two categories which fell into EMS or fire rescue.

What i learned

  • Which stations also show which area or district there are located where it gives us hints that the area they are in is safer, or dangerous.

Conclusion

Several stations consistently reported higher call volumes, suggesting concentrated emergency demand in those areas. Understanding these patterns is useful for operational planning, risk assessment, and also where to put the resources. While the data does not include detailed call types or precise geographic information, it still provides valuable insight into overall workload distribution.
